## C ↔ JS fidelity

`csym` on upstream is `calendar.c:120–175` and still calls `getlt()`. Patch 001 (`nethack-c/patches/001-deterministic-runtime.patch`) replaces that with `time()` + `localtime()` so `getnow` does not recurse. No RNG.

`strlen == 14` is `cStrlen`. The six copies are 4, 2, 2, 2, 2, 2 characters, then `atoi`. `atoi` skips space, tab, newline, vertical tab, form feed, and CR, then an optional sign, then digits. `"00"` is 0. The old `|| 1970` / `|| 1` substitution is gone.

The patch copies the host `struct tm` and overwrites year, month, day, hour, minute, and second, leaving `tm_isdst` as `localtime` set it. JS copies `contestRecorderLocaltime()`, whose `tm_isdst` is 1, then overwrites the same six fields. September 2026 in `America/New_York` is EDT, so `localtime(now)` on that recorder is `tm_isdst == 1`. A winter host would copy 0. The map names that freeze (D-1989): public stamps stay on the EDT offset instead of following the judge's current DST.

`mktime` builds `Date.UTC` from `1900 + tm_year` and the other civil fields. Years 0..99 are put back with `setUTCFullYear` because `Date.UTC` maps them onto 1900..1999. `tm_isdst > 0` subtracts −4 h (EDT). `== 0` subtracts −5 h (EST). `< 0` uses `nyOffsetSecs`. This caller always passes 1, so the epoch is civil-as-EDT, the same `+4 h` the old body used for a normal stamp. A non-finite result is -1. `timeresult === -1` falls through to 0. The `#if 0` `debugpline1` (`calendar.c:166–170`) is the empty arm.

`getnow` returns the parsed stamp when it is not 0, else `Date.now()` seconds. That is the patch's `parsed != 0` test.

Save captures `start_timing`, sets the live value to `getnow()`, and writes `yyyymmddhhmmss` of the captured value (`save.c:288–292`, `save.js:508–586`). Restore parses `ubirthday` and the start stamp, then sets `start_timing = getnow()` (`restore.c:615–625`, `save.js:825–834`). The parsed start is overwritten, as in C.

## Hallucinations / overclaim

The subject says the copied `struct tm` is the recorder's EDT `localtime`, not `getlt()` and not the host clock. The patch does call `localtime(time())`. Freezing `tm_isdst` at 1 is the named D-1989 choice so a winter run does not move those epochs. It is not a claim that the patch source contains the literal 1. `sfexpasc.c:810` is named and absent. A missing `ubirthday` string on an older JS payload leaves the pre-restore value; C's save file always has the 14 characters. New saves write the key.
